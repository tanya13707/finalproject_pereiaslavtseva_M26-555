# ValutaTrade Hub

Это учебное консольное приложение для работы с виртуальным валютным портфелем.

В приложении можно зарегистрироваться, войти в свой аккаунт, покупать и продавать валюту, смотреть балансы и получать курсы.

Все деньги в приложении виртуальные.

## Что используется в проекте

- Python 3.12 или новее.
- uv - для установки зависимостей и сборки проекта.
- requests - для получения данных из API.
- prettytable - для вывода таблиц.
- Ruff - для проверки кода.
- JSON-файлы - для хранения данных.

## Структура проекта

Основные файлы и папки:

- `main.py` - запуск приложения.
- `valutatrade_hub/core/` - классы пользователей, кошельков и валют, операции и исключения.
- `valutatrade_hub/cli/interface.py` - команды приложения и вывод сообщений.
- `valutatrade_hub/infra/settings.py` - загрузка настроек.
- `valutatrade_hub/infra/database.py` - чтение и запись JSON-файлов.
- `valutatrade_hub/parser_service/config.py` - настройки API.
- `valutatrade_hub/parser_service/api_clients.py` - получение курсов.
- `valutatrade_hub/parser_service/storage.py` - сохранение курсов и истории.
- `valutatrade_hub/parser_service/updater.py` - обновление курсов из двух источников.
- `valutatrade_hub/parser_service/scheduler.py` - обновление через заданный интервал.
- `valutatrade_hub/decorators.py` - запись операций в лог.
- `valutatrade_hub/logging_config.py` - настройка файлов логов.
- `data/` - файлы с данными.
- `pyproject.toml` - настройки проекта и зависимости.
- `uv.lock` - версии зависимостей.
- `.gitignore` - файлы и папки, которые не добавляются в Git.

## Установка

Для работы нужны Python 3.12 или новее и uv.

Скачайте проект или склонируйте репозиторий. Откройте терминал в папке проекта и выполните:

```powershell
uv sync
```

Все команды ниже нужно запускать из корня проекта, где находится `pyproject.toml`.

## Получение API-ключа

В проекте используются два источника:

- CoinGecko - для криптовалют.
- ExchangeRate-API - для обычных валют.

Для ExchangeRate-API нужно зарегистрироваться на сайте:

https://www.exchangerate-api.com/

После регистрации и подтверждения почты скопируйте API-ключ из личного кабинета.

В терминале PowerShell выполните:

```powershell
$apiSecret = Read-Host "Вставьте API-ключ" -AsSecureString
```

Вставьте свой ключ и нажмите Enter. Ввод будет скрыт.

Затем выполните:

```powershell
$env:EXCHANGERATE_API_KEY = [System.Net.NetworkCredential]::new("", $apiSecret).Password
```

Ключ будет доступен приложению в этом терминале. В новом терминале его нужно задать снова.

Ключ не нужно вставлять в Python-файлы или добавлять в Git.

Файл `.env` указан в `.gitignore`, но приложение не читает его автоматически.

## Запуск приложения

```powershell
uv run valutatrade
```

Также можно запустить через `main.py`:

```powershell
uv run python main.py
```

После запуска появится приглашение:

```text
valutatrade>
```

Команды нужно вводить по одной строке.

- `help` - посмотреть справку.
- `exit` - выйти из приложения.

Вход и сделки нужно выполнять в одном запуске приложения. После перезапуска потребуется войти снова.

## Регистрация и вход

Внутри приложения:

```text
register --username demo_user --password demo12345
login --username demo_user --password demo12345
```

Имя пользователя должно быть непустым и уникальным. Пароль должен содержать не меньше четырёх символов.

Пароль не сохраняется открытым текстом. Для него вычисляется SHA-256 с индивидуальной солью.

После регистрации создаётся пустой портфель.

## Виртуальные средства для проверки

Отдельной команды пополнения в CLI нет. Для демонстрации можно добавить виртуальные USD через Python.

Сначала зарегистрируйте пользователя `demo_user`, как в примере выше. Затем выйдите из приложения командой `exit`.

В PowerShell выполните:

```powershell
uv run python
```

После появления `>>>` вводите строки по очереди:

```python
from valutatrade_hub.core.usecases import login, load_portfolio, save_portfolio
user = login("demo_user", "demo12345")
portfolio = load_portfolio(user)
portfolio.add_currency("USD")
portfolio.get_wallet("USD").deposit(1000)
save_portfolio(portfolio)
exit()
```

В портфеле появится 1000 виртуальных USD.

При повторном выполнении этого примера добавится ещё 1000 USD.

## Обновление курсов

В PowerShell:

```powershell
uv run valutatrade update-rates
```

Обновление только криптовалют:

```powershell
uv run valutatrade update-rates --source coingecko
```

Обновление только обычных валют:

```powershell
uv run valutatrade update-rates --source exchangerate
```

Если один источник недоступен, приложение продолжит работу со вторым. При этом появится сообщение о частичном обновлении.

Старые курсы другого источника останутся в кеше.

## Просмотр курсов

Все сохранённые курсы:

```powershell
uv run valutatrade show-rates
```

Курс одной валюты:

```powershell
uv run valutatrade show-rates --currency RUB
```

Две самые дорогие криптовалюты:

```powershell
uv run valutatrade show-rates --top 2
```

Курсы относительно EUR:

```powershell
uv run valutatrade show-rates --base EUR
```

Параметр `--top` сравнивает цену одной единицы криптовалюты.

Поддерживаются USD, EUR, GBP, RUB, BTC, ETH и SOL.

## Покупка, продажа и просмотр портфеля

Сначала обновите курсы и запустите приложение:

```powershell
uv run valutatrade update-rates
uv run valutatrade
```

Затем вводите команды внутри приложения:

```text
login --username demo_user --password demo12345
show-portfolio
buy --currency EUR --amount 10
sell --currency EUR --amount 2
show-portfolio --base EUR
get-rate --from USD --to BTC
exit
```

Параметр `--amount` - это количество покупаемой или продаваемой валюты, а не сумма в долларах.

При покупке средства списываются с USD-кошелька. Если кошелька покупаемой валюты ещё нет, он создаётся автоматически.

При продаже валюта списывается из её кошелька, а выручка поступает в USD.

После сделки выводятся количество валюты, курс, стоимость или выручка и новый баланс.

Для покупки, продажи и просмотра портфеля нужно войти в аккаунт. Смотреть и обновлять курсы можно без входа.

## Хранение данных

Данные находятся в папке `data`:

- `users.json` - пользователи, хеши паролей, соль и дата регистрации.
- `portfolios.json` - кошельки и балансы пользователей.
- `rates.json` - последние сохранённые курсы.
- `exchange_rates.json` - история полученных курсов.

В `rates.json` курсы находятся в словаре `pairs`. Для каждой пары сохраняются значение курса, время и источник.

Поле `last_refresh` содержит время последнего обновления кеша.

В истории у каждой записи есть ID из валютной пары и времени. Одинаковые записи с тем же ID повторно не добавляются.

Сохранённый текущий курс заменяется только более свежим.

Запись каждого файла выполняется через временный файл с последующей заменой исходного. Два файла не записываются одной общей транзакцией.

Проект рассчитан на последовательную работу. Одновременный запуск нескольких процессов записи не поддерживается.

## Срок актуальности курсов

По умолчанию курс считается свежим 300 секунд, то есть пять минут.

Если курс устарел, покупка, продажа и расчёт портфеля не выполняются. Приложение предлагает обновить курсы.

Команда `show-rates` показывает сохранённые значения, но отмечает устаревшие курсы.

Время записывается в UTC. Это время получения ответа парсером, а не время обновления цены у самого поставщика.

Курсы сохраняются относительно USD. Для расчёта относительно другой валюты используются два курса к USD.

## Настройки

Общие настройки загружает `SettingsLoader`.

Для настроек и работы с JSON используется Singleton через `__new__`, чтобы в приложении был один общий экземпляр каждого менеджера.

При необходимости в `pyproject.toml` можно добавить:

```toml
[tool.valutatrade]
data_dir = "data"
rates_ttl = 300
default_base_currency = "USD"
logs_dir = "logs"
log_level = "INFO"
log_format = "%(levelname)s %(asctime)sZ %(message)s"
log_max_bytes = 1000000
log_backup_count = 3
```

Адреса API, список валют, время ожидания ответа и интервал обновления находятся в `parser_service/config.py`.

По умолчанию ожидание ответа API составляет 10 секунд.

## Обновление по таймеру

В терминале с заданным API-ключом выполните:

```powershell
uv run python -m valutatrade_hub.parser_service.scheduler
```

Обновление будет запускаться через 300 секунд после завершения предыдущей попытки.

Можно указать другой интервал:

```powershell
uv run python -m valutatrade_hub.parser_service.scheduler --interval 600
```

Для остановки нажмите Ctrl + C.

## Логи и обработка ошибок

Логи создаются в папке `logs`:

- `actions.log` - покупки, продажи и ошибки операций.
- `parser.log` - получение и обновление курсов.

Формат логов текстовый. Уровень по умолчанию - INFO, время - UTC.

Когда лог достигает примерно 1 МБ, создаётся новый файл. Сохраняются три предыдущих файла.

Декоратор `log_action` записывает пользователя, валюту, количество, курс и результат операции. При включённом `verbose` также записываются балансы до и после успешной сделки.

Если возникает ошибка, декоратор записывает её и передаёт дальше. CLI показывает сообщение пользователю.

Используются свои исключения:

- `InsufficientFundsError` - недостаточно средств.
- `CurrencyNotFoundError` - неизвестная валюта.
- `ApiRequestError` - ошибка получения данных из API.

Примеры команд для проверки ошибок:

```text
get-rate --from ABC --to USD
sell --currency EUR --amount 999999
buy --currency EUR --amount -1
```

Для проверки сделок сначала нужно войти в аккаунт и обновить курсы.
